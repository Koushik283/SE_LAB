## Project
**Automated Rubric Assignment Evaluator (ARAE)**

## Objective
To convert the functional requirements from Lab 1 into Agile Epics and User Stories, prioritize and estimate the backlog using Story Points, simulate a Scrum Sprint in Jira, and analyse the Sprint progress using a Burndown Chart.

## Tools Used
- Jira Software
- GitHub

## Lab Activities
1. Created a Jira Scrum project for the Automated Rubric Assignment Evaluator.
2. Converted Lab 1 requirements into Epics and User Stories.
3. Prioritized the User Stories based on user impact.
4. Assigned Story Points using Fibonacci-based estimation.
5. Created and populated Sprint 1.
6. Simulated the Sprint using the To Do → In Progress → Done workflow.
7. Generated and analysed the Sprint Burndown Chart.
8. Answered the reflection questions based on the Sprint results.
